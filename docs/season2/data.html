What is real, what is modelled

Real

  • Prices, volumes, dividends and splits for every traded symbol: vendor daily bars under data/real/prices/yahoo/, each file hashed and listed below. Yahoo is an aggregator, so its class is SECONDARY; the primary record is the exchange's consolidated tape, which is not redistributable.
  • The market and volatility path: FRED SP500 and VIXCLS daily closes, i.e. the official reserve-bank series.
  • The calendar: FRED's observation dates, so holidays are the real ones rather than a hand-typed list.
  • The events: SEC EDGAR Form 4 filings, openFDA decisions, the official MLB schedule feed, NOAA/NCEI daily summaries, FRED yields and the Kalshi settled-market list, each with the endpoint recorded.

Modelled (declared, and stress-tested)

  • The intraday path inside each real daily bar: the open/high/low/close and volume are real, but the sequence of prices between them is not observable from daily data.
  • The venue: quoted spread, displayed depth, impact, participation cap, borrow fees and market-maker behaviour, all as declared in sim/config.py and registered as IR-40 to IR-46.
  • Dividend treatment is real in amount and date, but the vendor's event feed (not the issuer's own announcement) is the source.

Not retrieved

  • Consolidated-tape intraday history, which would be the only way to make the intraday path real. No free, redistributable tape exists.
  • An archived NFL/NBA injury series and pre-game model snapshots: those documents are published live, so the strategies that read them run forward-only.
