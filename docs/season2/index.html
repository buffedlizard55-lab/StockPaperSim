Season 2 — the MasterFeed Invitational

Fourteen strategies derived from the MasterSite project directory, each with its own username, each given $100,000 of paper money and one year of real collected prices (2025-09-17 → 2026-09-16, 251 sessions). Every fill is written to a ledger that carries the session's real open, high, low, close and volume, the file and SHA-256 those came from, the participation rate against the real volume, and the full cost breakdown. The intraday path inside each real bar is still modelled; that, and everything else modelled, is named in the data custody page and the irregularity register.

Read this first

Three things separate this season from a typical backtest:

  1. The prices are real and individually traceable. Each participant page lists fills next to the real close for that session and the data file the price came from. scripts/independent_audit_season2.py re-derives every published number from those files without importing the simulation.
  2. A missing signal is reported, not filled in. Where a source could not be retrieved as history (injury feeds, pre-game model predictions), the strategy is registered as forward-only and places no backdated trades.
  3. The venue is stress-tested, not assumed. The same real prices are re-traded with doubled costs and with thinner displayed liquidity, and every participant's return is published under all three assumptions.
