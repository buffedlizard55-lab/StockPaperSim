A round trip is an average-cost lot: a fill that reduces an opposite lot closes it, a same-side fill blends into it, and a fill that crosses zero closes the old lot and opens a new one in the other direction. The same rule is implemented twice - once inside the engine to compute the account, and once in sim/ledger.py to check it.

Season 2 trades real, collected daily prices (Yahoo Finance chart API files under data/real/prices/, cross-checked against the Nasdaq quote API and the Federal Reserve Bank of St. Louis' SP500 series) and real dated events (SEC EDGAR Form 4, FDA openFDA, MLB StatsAPI, NOAA/NCEI, FRED, Kalshi). The intraday path inside each real daily bar is still modelled, the venue is still modelled, and dividends come from a vendor event feed rather than the issuer - all three are declared in the irregularity register and on the data custody page. Nothing here is investment advice.

Built from run memory and collected data by scripts/build_site_season2.py. Every file is SHA-256 checksummed in its run manifest.
