Official-price eligibility: NOT ELIGIBLE

This committed run uses yahoo price files classed SECONDARY. It is reproducible research, not an official-price competition result. The strict runner uses the Nasdaq adapter and refuses to trade when official files, raw checksums, complete dates, OHLCV validation or redistribution permission are missing.

Audit flags: DATE_RANGE, DIVIDEND_DATA_NOT_VERIFIED, DIVIDEND_PROVENANCE_MISSING, MANIFEST_CHECKSUM_NOT_FOUND, MISSING_SESSIONS, NON_OFFICIAL_SOURCE_CLASS, REDISTRIBUTION_NOT_CONFIRMED. Run python3 -m sim.cli price-audit for the complete report; no Yahoo/Nasdaq agreement can override this gate.

Forward-only: the strategies that place no backdated trades

4 of 14 items have no retrievable official history:

  • NFL Injury — nfl.com publishes the current week's injury designations; there is no official archive endpoint for a past season that this project could retrieve, so the injury rule runs forward from the next collection instead of being backdated. ESPN's archive is a secondary feed and is used only for scores, never as the official injury designation.
  • NBA Injury — The NBA publishes its injury report as a dated PDF; the 2025-26 archive is not retrievable as a machine-readable series, so the rule is forward-tested against the live document (whose existence is verified and hashed in data/real/sports/official/).
  • NCAA Scoreboard — The NCAA scoreboard endpoint is official but the archived 2025-26 season had to be probed rather than enumerated; the same attention rule that is backtested on MLB scores runs forward on NCAA weeks.
  • Sports Pred — SportsPred emits pre-game probabilities. There is no archived, timestamped snapshot of those predictions for the past season, so a backtest would have to recompute them - which would be this project's model, not the site's. The participant therefore trades only on snapshots collected from now on.

Those strategies exist in the roster, their adapters point at the live official document, and they report no trades for the season rather than a number built from data this project could not verify. A scheduled collection run is what turns them into backtestable participants, and that is the first item in the remaining-work register.

Where the money actually came from

The register answers "could it be measured"; the participant pages answer "did it make money, and why". Each carries the strategy as declared before the run, its returns, a post-mortem built from measured quantities only - never from the strategy's own priors - its round trips with the collected reference prices, and its verification block.
