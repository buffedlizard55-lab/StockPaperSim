Are the results statistically real?

A ranking is a point estimate. This page tests the published season's own numbers for three failure modes of a one-year contest: a Sharpe ratio that a lucky path produces, an alpha that vanishes under resampling, and a winner who is only the winner of the one scenario that actually happened. The estimators live in sim/significance.py; every number below is re-derived from the committed equity panel of season1-primary-seed20260917 (2025-09-17 → 2026-09-16).

1/20 participants whose 95% bootstrap Sharpe interval excludes zero
2 wins across 6 scenarios for the published leader (@BetaChaser_3xProxy) — chance is 5% per scenario

What is computed, and what each test assumes

  • Bootstrap intervals — iid percentile bootstrap, 2000 replicates, resampling each participant's own daily returns; iid understates the uncertainty of autocorrelated series, so read each interval as a floor.
  • Deflated Sharpe Ratio — Bailey & Lopez de Prado (2014); n_trials = roster size (20); trial Sharpe variance from the estimator's asymptotic variance because committed memory holds scenario totals, not scenario curves. The trial count is the roster size: twenty strategies were run against the same tape, so the bar a winner must clear is the expected best of twenty, not zero.
  • Rank test — exact binomial tail on scenario wins against the 1/N chance level.

Read the p-values as one-sided: the probability that a participant with no skill wins at least this many of the 6 scenarios by chance. A winner confirmed in every scenario still holds one calendar year's worth of evidence (L-17) — the test bounds the luck, it does not repeal it.

StockPaperSim is a research and education project. Every price series a participant traded on is either a real published observation (FRED S&P 500 and VIX closes, Yahoo Finance monthly SPY bars and AAPL bars/dividends) or an explicitly labelled simulation of it. Nothing here is investment advice, and no result on this site should be read as evidence about a strategy's real future performance. See Limitations.
