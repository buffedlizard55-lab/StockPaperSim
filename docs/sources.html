Environment note. The sandbox this was built in could reach pypi.org, files.pythonhosted.org, api.github.com, github.com and codeload.github.com directly. Every other URL above was reached through the page-fetch tool, or through search-result text where fetching failed. Several market-data hosts refused the connection outright, which is why Season 1 is a replay of real anchor data rather than a live feed - see L-01.

StockPaperSim is a research and education project. Every price series a participant traded on is either a real published observation (FRED S&P 500 and VIX closes, Yahoo Finance monthly SPY bars and AAPL bars/dividends) or an explicitly labelled simulation of it. Nothing here is investment advice, and no result on this site should be read as evidence about a strategy's real future performance. See Limitations.

Built from run memory by scripts/build_site.py. Data integrity: every file is SHA-256 checksummed in its run manifest.
