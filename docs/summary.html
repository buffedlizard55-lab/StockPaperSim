Executive summary

One page, every headline row. Rows that carry numbers name the file the numbers came from; rows that do not carry numbers say not run and why. The distinction is the whole point of this page: a forward test with an invented row in it is worth less than a shorter test without one.

How the forward prints were obtained

The publisher rows in this build were transcribed from the endpoints below in a session that had no outbound HTTPS, and cross-checked against each other. Each row keeps the publisher's own string and the URL it came from; the scheduled workflow fetches the same endpoints directly so the next build does not need the transcription step at all.

    Standing rules this page obeys

    • No manual input: every scheduled run collects, settles, rebuilds the site and opens its own pull request.
    • No invented numbers: a missing measurement is published as NOT RUN with the reason and the artifact that would unblock it.
    • Irregularities are flagged rather than smoothed: every one is itemised on the irregularities page with its evidence.
    • Yahoo-backed results are secondary research data and are labelled as such on every page that shows them.
